|------|------|

| 연동 | mes `app_mes` 적재, lake `app_spark` 복제, 조회 `app_lake`·JH 화면(이후). MS init/Spark 잡 반영 요청 |
| 개발 목적 (사람 주도) | 원본 PC 이미지 삭제 전 mes DB 적재·lake 조회 SoT, 타 PC Docker 검증 |
| 관련 경로 | `DH/api/image_pipeline/`, `DH/data/sql/03_casting_image.pg.sql`, `DH/지침_image_pipeline_임시.md`, `DH/전달사항/2026-11-19_*` |
| 변경 (2026-11-19, JH 작업·DH/MS 승인) | 모드 A 소비(`flink_role_a.py`)를 Flink job `MS/db/flink/jobs/image_ingest.py` 로 이전·삭제. 같은 검사·SQL·spark_sync 형식, DB 일시 오류는 재시도(유실 방지). 서버 테이블 생성·E2E(mes→lake) 통과. 서버 실행법: `JH/전달사항/2026-11-19_DH_이미지수집_Flink_서버실행.md` |
