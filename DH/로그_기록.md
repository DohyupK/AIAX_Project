# DH 로그 기록

모든 로직·에러에는 로그를 남깁니다.  
정식 배포 전에 **지울 로그**와 **지우면 안 되는 로그**를 분류해 둡니다.

## 지우면 안 되는 로그 (유지)

| 코드/위치 | 내용 | 이유 |
|-----------|------|------|
| `dh.image_pipeline` — casting_id, mode, mes/lake 성공·실패 | 이미지 적재·복제 추적 | 원본 URI 삭제 후 장애 분석 |
| 타 PC E2E 결과 요약 (`전달사항/2026-11-19_타PC_…`) | 검증 통과/실패 | 2차 인수 |
| (예) | request_id, 에러 코드 | 운영·감사 |

## 지울 로그 (배포 시 제거·레벨 하향)

| 코드/위치 | 내용 | 이유 |
|-----------|------|------|
| dry-run 요청 전체 body (`image_base64` 전문) | Base64 본문 | 용량·민감 — 길이·해시만 남길 것 |
| status_server 디버그 | 개발용 | 배포 시 INFO 이상만 |
| (예) | 디버그 print, 상세 body | 개발용 |
