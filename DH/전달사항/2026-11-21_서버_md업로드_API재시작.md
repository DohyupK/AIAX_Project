# 서버 — .md 업로드 허용 반영 (API 재시작)

| 항목 | 내용 |
|------|------|
| 증상 | 문서함 `.md` 업로드 시 `허용되지 않는 형식…` (목록에 md 없음) |
| 원인 | 코드(`paths.py` ALLOWED_EXT에 `md`)는 `origin/dev`에 있음. **실행 중 API가 옛 코드** |
| 프론트 `.env` | `NEXT_PUBLIC_API_BASE_URL=https://gknushift.freemyip.com` → 로컬 재시작만으로는 안 됨 |

## 서버에서 (NCP `/root/AIAX_Project`)

```bash
cd /root/AIAX_Project
git pull origin dev
# md 확인
grep -n md JH/api/documents/paths.py
systemctl restart myapp
```

확인: 문서함에서 `.md` 다시 업로드 → 200. 거절 시 detail 목록에 `md`가 보이면 아직 미반영.

로컬 PC에서 SSH 재시작 시도했으나 `Permission denied (publickey)` — 서버 키로 DH가 위 명령 실행 필요.
