# 전달사항 — 사내 문서 청킹 자정 재처리 (DH → MS)

- 작성: DH, 2026-11-19
- 대상: MS (`lake_runner` / Spark 00:00 KST)
- 상태: JH API·org 테이블은 DH/JH 반영. **실행기 연동은 MS**

## 배경

사내 문서함 업로드 후 청킹·OpenAI 임베딩 예외 사다리:

1. 즉시 최대 2회  
2. 실패 시 5분 후 1회  
3. 또 실패 → `org.document_chunk_job.chunk_status = midnight_pending`  
4. **매일 00:00 KST** 기존 lake 동기와 **같이** 재청킹

## 요청

[`MS/db/apps/src/apps/lake_runner.py`](../../MS/db/apps/src/apps/lake_runner.py) 가 00:00 KST에 Spark `lake_sync` 돌릴 때, 같은 사이클에서 아래를 한 번 호출:

```bash
cd /root/AIAX_Project/JH/api   # 서버 경로 기준
uv run python -m documents.rechunk
```

- 환경: 루트 `.env` 에 `DOCS_DATABASE_URL`, `DOCUMENT_ROOT`, `OPENAI_API_KEY` 필요
- 성공/실패 JSON stdout (`ok` / `fail` / `total`). fail > 0 이어도 lake_sync 는 막지 말 것(문서 청킹은 부가)

## org 테이블 (서버 반영됨)

| 테이블 | 역할 |
|--------|------|
| `org.document_chunk_job` | `pending` / `ok` / `retry_5m` / `midnight_pending` |
| `org.document_chunk_embedding` | OpenAI 벡터 (`real[1536]`, pgvector 시스템 패키지 없음) |

DDL 사본: [`DH/data/sql/04_company_document_embedding.pg.sql`](../data/sql/04_company_document_embedding.pg.sql)

## pgvector (선택)

NCP Postgres에 `vector` 확장이 **시스템 미설치**라 `CREATE EXTENSION vector` 실패함.  
가능하면 `postgresql-XX-pgvector` 설치 후 `vector(1536)` 이전을 검토해 주세요. 지금 검색은 앱에서 코사인.
