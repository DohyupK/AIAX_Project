# DB연동_내역

정식 PostgreSQL은 **아직 사용하지 않습니다.**  
시각 확인·테스트용은 각 개인 폴더 `data/` 아래 **SQLite 목업**을 씁니다.

이 폴더에는 **누가 / 언제 / 어떤 기능이 / 어떤 목업 DB·테이블을** 썼는지 기록합니다.  
기록이 비면 나중에 서버·Postgres 이관 때 추적이 어려워집니다.

## 어떻게 기록하나

1. 개인 폴더에서 SQLite를 쓰거나 스키마를 바꾸면  
2. [`기록_양식.md`](기록_양식.md)를 복사해 `YYYY-MM-DD_이니셜_기능명.md`로 저장하거나, 양식 표에 한 행을 추가합니다.  
3. 업무일지·기능표에도 해당 기능을 남겨 둡니다 ([AGENTS.md](../AGENTS.md) 7·10항).

## 규칙 요약

- DB 파일(`.db`)은 Git에 올리지 않습니다.
- 테이블·컬럼명은 소문자 `snake_case` 권장 (이후 Linux/PostgreSQL 대비).
- 연결은 열고 닫기·풀 관리에 신경 씁니다 (메모리·핸들 누수 방지).
