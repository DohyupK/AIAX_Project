## 4. 도메인 규칙

### 조직·접근 코드

- 접근 코드 = `position_code`(10000~70000) + `dept_code`(1000~7000) + 부서장 100 + `team_code`(10~60, 없음 0) + 팀장 1
- 소장(1명)은 경영부 부서장, 팀 없음 → 71100. 모든 사원이 같은 공식
- 부서장·팀장 원본은 `department.department_representative`, `team.team_representative`
- 페이지 권한은 접근 코드로만 구분. 기준표는 설명서 「페이지 권한」

### 하청·게이트

- 업체 `v0001` (주)한빛정밀 → 게이트 a, `v0002` 대성기공 → 게이트 b, 카드 `vc0001`~ (작업자 이름 없음)
- 게이트 a·b = 회사 정문. 정직원은 a·b 모두
- 게이트 정보는 `gate_card`(`gate_a`, `gate_b` boolean)에만

### 출입·근태

- 출입 로그: 게이트 통과마다 1행. IN 이면 `clock_in_at`만, OUT 이면 `clock_out_at`만, `in_out` = IN|OUT
- 근무 형태: 주조팀(casting1~3) 3조 3교대(06·14·22시, 팀별 1주 단위 순환), 그 외 정시 09~18
- 지각·조퇴·부족·초과근무는 트리거가 각자 근무 시간 기준으로 판정 (설명서 「근무 기준」)
- 결근 행은 직접 넣음 → 연차 1일 차감

## 5. 트리거 (DB가 자동으로 하는 일)

| 바뀌는 것 | 자동으로 바뀌는 것 |
|-----------|-------------------|
| `employee` 직급·부서·팀, 부서장·팀장 | `access_code`, `dept_roster`, `team_roster` |
| `employee_gate_log` IN | `attendance` 추가, `employee_card.attendance_status` = present |
| `employee_gate_log` OUT | `employee_record` 계산, `attendance_status` = absent, `last_logout_at` |
| `employee_record.absent` = true | `annual_leave_used` +1 (최대 15) |
| `employee.employment_status` = resigned (퇴사일 필수, 부서장·팀장 불가) | 사원증 게이트 a·b 차단 (재직으로 돌리면 다시 열림) |
| org 테이블 전부 (앱 기록 제외) | `change_log` |

### 아직 없음

| 항목 | 이유 |
|------|------|
| `change_log` → lake 복제 (Spark) | 작업 예정 |
| 월말 `monthly_overtime_hour` 초기화 | 스케줄러 없음 |
| 하루 마감 결근 자동 처리 | 스케줄러 없음 (지금은 직접 넣음) |
| 로그인·페이지 권한 미들웨어 | 앱 쪽 |
