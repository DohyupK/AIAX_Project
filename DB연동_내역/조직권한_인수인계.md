| 테이블 | 역할 | 행 |
|--------|------|-----|

## 4. 도메인 규칙 (생성규칙)

### 조직·권한번호

- 부서 10~70, 사원 53, 팀 casting1/2/3·maintenance·cost·TF (미배정 0)
- `access_code`: dept×10 + position/100, 팀장 +1, 소장 700 — **시드 전용** (로직 모듈 아님)
- `page.page_code` → `*_page`. PK `(dept, position, page_feature)`

### 하청·게이트

- 철자 `vender_*`. 업체 HB260601 / DS260601
- worker `card_id` = `{앞2소문자}{yymmdd}{a|b}` — **employee FK 없음**
- `gate_card`: `employee_card_id` / `vender_card_id`
  - 사원 카드 → gate_a·b 둘 다 O
  - vender 끝 a/b → 해당 게이트만 O

### 출입·근태

- `employee_gate_log` / `vender_gate_log`: work_date, clock_in/out, commute_type IN|OUT
- vender 로그 FK → `gate_card.vender_card_id`
- `employee_record`: actual_hour, overtime_hour(actual−9, ≤0 null), late/early_leave/absent/work_deficit (사유 없음)
- late/early: **자동 판정 로직 없음**. 시드 예시값만 가능

### employee_status

| 컬럼 | 규칙 |
|------|------|
| monthly_overtime_hour | actual−10, ≤0이면 null (월 초기화 의도) |
| last_logout_at | 최후 clock_out |
| annual_leave_used | absent 시 +1, 최대 15 |
| years_of_service | 오늘 − employee.created_at |

## 5. 규칙 로직 모듈

`DH/api/common/org_permission_logic.py` — DB/FastAPI 없음. Postgres 행 계산에도 동일 사용.

### 구현됨

| 함수 | 내용 |
|------|------|
| `compute_actual_hour` | 출근~퇴근 |
| `compute_overtime_hour` | actual−9, ≤0→null |
| `compute_monthly_overtime_hour` | actual−10, ≤0→null |
| `compute_years_of_service` | 근속년수 |
| `gate_flags_for_employee` / `gate_flags_for_vender_card` | 게이트 O 규칙 |
| `build_vender_card_id` | card_id 문자열 |
| `clamp` / `bump_annual_leave_used` | 연차 0~15 |
| `build_employee_record_fields` | actual/OT (+ late/early는 인자만) |

### 모듈에 두지 않음

| 항목 | 이유 |
|------|------|
| access_code 계산 | 시드 전용 |
| 지각/조퇴 자동 판정 | 미지시 → 제거 |

### 미구현 (앱·인프라)

| 항목 | 이유 |
|------|------|
| 월말 monthly OT 자동 초기화 | 스케줄러 없음 |
| 게이트 실시간 IN/OUT | 이벤트·API 없음 |
| DB 트리거로 status/record 동기화 | 앱 레이어 없음 |
| 페이지 RBAC 미들웨어 | 세션·조회 없음 |
| 로그인 / last_logout 실기기 | 인증 없음 |
| FastAPI로 SELECT→로직→UPDATE | 라우트 없음 (로직 모듈은 준비됨) |
| late/early/absent 사유·승인 | 워크플로 미정 |
| work_deficit 상세 산식 | 플래그만 |
