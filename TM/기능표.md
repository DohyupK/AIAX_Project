## 기능 목록

### XGBoost 모델 이식 (`xgb_model`)

| 항목 | 내용 |
|------|------|
| 주요 기능 | 주조/설비 피처 기반 PassOrFail(정상/불량) 예측용 XGBoost 모델 아티팩트 + TM uv 런타임 |
| 세부 기능 | joblib 로드·`predict_proba` 예측 / XGBoost 네이티브 JSON(선택) / 피처 17개 고정 순서 / `molten_capacity` NaN 허용 / 임계값 기본 0.5 |
| 기술스택 | `TM/` uv 프로젝트 — 직접 의존: `xgboost`, `scikit-learn`, `joblib`, `pandas`, `numpy` (하위: `scipy` 등 → `uv.lock`) |
| 연동 | 페이지·API·루트 셸 연동 없음. 아티팩트 `TM/xgb_model/`, 환경은 `TM/pyproject.toml` |
| 개발 목적 (사람 주도) | 학습된 모델을 팀 워크스페이스에 이식해, 이후 TM 예측 API/페이지에서 동일 전처리·피처 순서로 재현 가능하게 함 |
| 관련 경로 | `pyproject.toml`, `uv.lock`, `xgb_model/model_xgb2_missing_test.joblib`, `xgb_model/model_xgb2_missing_test.json` |

#### 피처·전처리 (이식 스펙)

- **피처 17개 (순서 고정):** `mold_temperature`, `facility_CycleTime`, `production_CycleTime`, `mechanical_strength`, `molten_capacity`, `injection_pressure`, `sleeve_temperature`, `top_temp1`~`top_temp4`, `bottom_temp1`~`bottom_temp4`, `biscuit_thickness`, `cooling_water_temp`
- **제외:** `line_unit`, `production`, `timestamp`, `date`, `production_count`, `PassOrFail`
- **타깃:** `PassOrFail` (0=정상, 1=불량). `molten_capacity` NaN 허용. 그 외 결측/스케일링 없음
- **학습 전제:** Train=`molten_capacity` 비결측 / Test=결측(~22%), `n_estimators=100`
- **로드 확인 (2026-11-07):** `uv run` + joblib → `XGBClassifier`, `n_features_in_=17`
