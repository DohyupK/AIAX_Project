## 기능 목록

### 주조 불량 예측 최종 모델 v1.0 (`model/final_model/casting_passorfailML`)

| 항목 | 내용 |
|------|------|
| 주요 기능 | 주조 샷의 센서값 8개(원본 7 + 파생 1)로 PassOrFail(0=정상, 1=불량)을 예측하는 최종 XGBoost 모델 |
| 세부 기능 | `predict_proba` 불량 점수 → 기준값 0.572 이상이면 불량 판정 / pkl 하나에 모델·피처 순서·전처리 규칙·기준값·성적이 함께 저장됨 |
| 기술스택 | XGBoost 이진분류 `XGBClassifier(tree_method='hist', random_state=0)`. 런타임은 `TM/` uv 프로젝트(`xgboost`, `scikit-learn`, `numpy`, `pandas`). pkl 내부가 `numpy._core` 경로를 써서 **numpy 2.x 이상 필요** |
| 연동 | 아직 없음 (API·페이지·루트 셸 미연결). 연결 시 TM 예측 API → JH 품질 검사 화면 `prob` 교체 방식 검토 중 |
| 개발 목적 (사람 주도) | 실험 모델 53개(01~08) 비교 끝에 고른 설정을 전체 데이터로 다시 학습해, 실제 공정 데이터에 바로 쓸 수 있는 배포용 모델을 확보 |
| 관련 경로 | `model/final_model/casting_passorfailML/20261114_XGBoost_casting_v1.0.pkl`, `…_v1.0_validated.pkl`, 선정 근거 [models_list/README.md](model/models_list/README.md) |

#### 파일 2개의 역할

| 파일 | 학습 데이터 | 역할 |
|------|-------------|------|
| `20261114_XGBoost_casting_v1.0.pkl` | 전체 100% (73,611샷, 런 1~64) | **배포용.** 따로 떼어 둔 평가 데이터가 없어 자체 성적 없음 → 아래 validated 성적을 참고로 사용 |
| `20261114_XGBoost_casting_v1.0_validated.pkl` | 앞 80% (58,888샷, 런 1~47) | **성능 근거.** 나머지 20%(런 48~64, 14,723샷)로 Test |

두 파일은 하이퍼파라미터·피처·전처리·기준값이 같고 학습 데이터 범위만 다릅니다.

#### 입력·전처리 (순서 고정)

1. `pressure_low` = `injection_pressure < 600` 이면 1, 아니면 0
2. `top_temp1`
3. `top_temp2`
4. `bottom_temp1`
5. `bottom_temp2`
6. `biscuit_thickness`
7. `cooling_water_temp`
8. `mechanical_strength`

- 파생은 `pressure_low` 하나뿐이고 나머지 7개는 원본 컬럼 그대로. 스케일링 없음.
- 결측은 NaN 으로 넣으면 XGBoost 가 처리 (`missing=nan`).

#### 하이퍼파라미터

`n_estimators` 800, `learning_rate` 0.02, `max_depth` 6, `min_child_weight` 1, `reg_lambda` 1, `scale_pos_weight` 3, `subsample` 0.7, `eval_metric` logloss  
→ 실험 [08 상위 10 비교](model/models_list/README.md)의 `261114_XGB_08-02_rank2` 설정(Test PR-AUC 0.8297)과 같음.

#### 기준값 (threshold)

| 이름 | 값 | 설명 | Test 결과 (validated) |
|------|-----|------|------------------------|
| **기본: 검증값** | **0.572** | 앞 80% 시계열 CV 구간에서 F1 최대. Test 에서 성능 확인됨 | Recall 0.699 / Precision 0.938 / F1 0.801, 경보 434건 |
| 대안: 재계산값 | 0.686 | 전체 100% 시계열 CV 구간에서 F1 최대. 오경보 더 적음, **별도 검증 없음** | Recall 0.663 / Precision 0.965 / F1 0.786, 경보 400건 |

- 점수는 `scale_pos_weight=3` 때문에 실제 불량 확률보다 높게 나옵니다. 화면에는 "불량 확률 ○○%" 대신 점수·판정으로 표시하는 것을 권장.

#### Test 성적 (validated, 기준값 0.572, 런 48~64)

| PR-AUC | Recall | Precision | F1 | TP | FP | FN | TN | 경보 비율 | Test 불량률 |
|--------|--------|-----------|----|----|----|----|----|-----------|-------------|
| 0.8297 | 0.6993 | 0.9378 | 0.8012 | 407 | 27 | 175 | 14,114 | 2.95% | 3.95% |

- 해석: 불량 582건 중 407건을 잡고(Recall 70%), 경보 434건 중 407건이 실제 불량(Precision 94%).

### XGBoost 모델 이식 (`xgb_model`) — 이전 이식본

> 최종 모델 v1.0 이전에 이식한 모델(피처 17개)입니다. 현재 최종 모델과 피처 구성이 다릅니다. 유지·삭제 여부는 결정 필요.

| 항목 | 내용 |
|------|------|
| 주요 기능 | 주조/설비 피처 기반 PassOrFail(정상/불량) 예측용 XGBoost 모델 아티팩트 + TM uv 런타임 |
| 세부 기능 | joblib 로드·`predict_proba` 예측 / XGBoost 네이티브 JSON(선택) / 피처 17개 고정 순서 / `molten_capacity` NaN 허용 / 임계값 기본 0.5 |
| 기술스택 | `TM/` uv 프로젝트 — 직접 의존: `xgboost`, `scikit-learn`, `joblib`, `pandas`, `numpy` (하위: `scipy` 등 → `uv.lock`) |
| 연동 | 페이지·API·루트 셸 연동 없음. 아티팩트 `TM/xgb_model/`, 환경은 `TM/pyproject.toml` |
| 개발 목적 (사람 주도) | 학습된 모델을 팀 워크스페이스에 이식해, 이후 TM 예측 API/페이지에서 동일 전처리·피처 순서로 재현 가능하게 함 |
| 관련 경로 | `pyproject.toml`, `uv.lock`, `xgb_model/model_xgb2_missing_test.joblib`, `xgb_model/model_xgb2_missing_test.json` |

#### 피처·전처리 (이식 스펙)

- **피처 17개 (순서 고정):** `mold_temperature`, `facility_CycleTime`, `production_CycleTime`, `mechanical_strength`, `molten_capacity`, `injection_pressure`, `sleeve_temperature`, `top_temp1`~`top_temp4`, `bottom_temp1`~`bottom_temp4`, `biscuit_thickness`, `cooling_water_temp`
- **제외:** `line_unit`, `production`, `timestamp`, `date`, `production_count`, `PassOrFail`
- **타깃:** `PassOrFail` (0=정상, 1=불량). `molten_capacity` NaN 허용. 그 외 결측/스케일링 없음
- **학습 전제:** Train=`molten_capacity` 비결측 / Test=결측(~22%), `n_estimators=100`
- **로드 확인 (2026-11-07):** `uv run` + joblib → `XGBClassifier`, `n_features_in_=17`
