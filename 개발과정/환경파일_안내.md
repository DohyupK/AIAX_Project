# 환경 파일·gitignore 안내

Plan 모드에서는 `.env.example` / `.gitignore` 같은 비마크다운 파일 생성이 막힐 수 있습니다.  
Agent 모드에서 아래 내용을 해당 파일명으로 복사해 두세요. (또는 에이전트에게 「gitignore랑 env.example 파일로 만들어」요청)

---

## `.env.example` 내용

```text
# ============================================================
# .env.example 사용법
# ============================================================
# 1) 이 파일을 복사해 프로젝트 루트에 ".env" 라는 이름으로 만듭니다.
#    (Windows 예: copy .env.example .env)
# 2) 아래 플레이스홀더를 본인/팀 로컬 값으로 바꿉니다.
# 3) ".env" 는 GitHub에 올리면 안 됩니다. (.gitignore 에 포함됨)
# 4) 실제 API 키·비밀번호·토큰을 이 예시 파일에 적지 마세요.
# 5) 새 키가 필요하면: 라이브러리/기능 승인 후 여기에 이름만 추가하고,
#    실제 값은 각자 .env 에만 넣습니다.
# ============================================================

APP_ENV=development

# API_BASE_URL=http://127.0.0.1:8000
# WEB_BASE_URL=http://127.0.0.1:3000
# SOME_API_KEY=
```
