## 도구·패키지 매니저 (표준 확정)

| 구분 | 이름 | 오픈소스 | 비고 |
|------|------|----------|------|
| Python 패키지 매니저 | **uv** | 예 | 프로젝트 의존성에 `pip install` 금지 |
| Node 패키지 매니저 | **pnpm** | 예 | `npm`/`yarn` 혼용 금지. 설치: `pnpm install` (미설치 시 `npm exec pnpm install`로 부트스트랩 가능) |

### uv 공식 명령 (pip와 혼동 금지)

| 할 일 | 금지 | 공식 |
|-------|------|------|
| 패키지 추가 | `pip install X` | `uv add X` |
| 동기화 설치 | `pip install -r ...` | `uv sync` |
| 실행 | 임의 `python` | `uv run python ...` |

### pnpm lock 충돌

- **예방:** 기능 PR에서 lock을 자주 안 건드림. 패키지 추가는 승인 후 한 담당·한 PR. 이 표에 먼저 기록.
- **해결:** lock을 손으로 섞지 말고 `pnpm install`로 재생성 후 커밋.
