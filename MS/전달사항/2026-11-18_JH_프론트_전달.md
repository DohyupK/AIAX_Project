## 1. 인사 관리 — 퇴사 처리

| 바뀐 DB | `org.employee` 에 `employment_status`(`active`/`resigned`), `resigned_at`(date) 추가. 54명 모두 `active` |
|---|---|
| 규칙 | `resigned`면 `resigned_at` 필수, `active`면 NULL (DB가 막음). 부서장·팀장은 퇴사 불가 (DB 오류: 대표자를 먼저 바꾸라는 메시지). 퇴사하면 사원증 게이트 a·b가 자동으로 막힘 |
| 지금 연결된 곳 | `JH/api/hr/router.py` 사원 삭제, 상세 화면 삭제 버튼 |
| 이렇게 바꾸면 됨 | 행 삭제 대신 `UPDATE org.employee SET employment_status = 'resigned', resigned_at = CURRENT_DATE WHERE employee_no = …`. 버튼 이름 "퇴사 처리". 목록은 `employment_status = 'active'` 만 |

## 5. Model Management

`ai.model_registry` (모델 1행, 목업 없음 — 실제 모델을 등록)

| 컬럼 | 화면 항목 |
|---|---|
| `model_registry_idx` | Idx |
| `model_name`, `version` (둘이 PK) | 모델명, 버전 |
| `process_code` | 관리 공정: `CAST-OPT` 공정 최적화 / `CAST-QC` 품질 검사 / `SAFE-GATE` 안전 관리 |
| `description` | 설명 |
| `accuracy_score`, `recall_score`, `precision_score`, `f1_score` | 성과지표 (0~1, 필수) |
| `file_name`, `file_path` | 모델 파일 (선택). 파일은 서버 폴더에 두고 경로만 저장 — 폴더는 서버 관리자(DH)가 정함 |
| `deployed` | 배포 여부 |
| `created_at` | 생성일(= 등록일, 자동) |

| 규칙 | 공정마다 배포 1개. `deployed = true` 로만 바꾸면 같은 공정의 기존 배포는 DB가 자동으로 해제 |
|---|---|
| 지금 연결된 곳 | `JH/frontend/pages/model_management/data.ts` 목업 |
| 이렇게 바꾸면 됨 | 목록·등록·배포를 이 테이블로. 성과지표 컬럼명은 `*_score` (예약어 따옴표 피함) |

## 6. 보호구 착용 위반

| 테이블 | 내용 |
|---|---|
| `ai.ppe_gate_rule` | 게이트별 필수 보호구. a: 안전모·안전화·조끼·장갑·보안경 필수 / b: 보안경만 선택 (`false` = 선택) |
| `ai.ppe_check` | 카메라 판정 1번 = 1행. `employee_gate_log_idx` 또는 `vendor_gate_log_idx`(출입 로그 IN), `helmet`·`shoes`·`vest`·`gloves`·`goggles`(착용 여부, 판정 불가면 NULL), `result`(`pass`/`violation`/`undecidable`), `manual_result`·`manual_by`(판정 불가 건 안전관리자 확인) |

| DB 기준 | 게이트 a·b = 회사 정문. 카메라는 주조팀(casting1~3)과 하청 카드만 켜짐. 하청: 한빛정밀(v0001) a, 대성기공(v0002) b. 사람은 사번 `e0001`~, 사원증 `ec0001`~, 하청 카드 `vc0001`~ |
|---|---|
| 목업 | 2026-08-04~10-11 출입 IN 중 주조팀·하청 2,756건, 위반 82 (1,000회당 29.8), 판정 불가 7 (안전부 부서장 e0039 확인) |
| 지금 연결된 곳 | `JH/frontend/pages/ppe_violation/data.ts`·`monthly.ts` 목업 (게이트 A=주조·B=품질, U-xxxxx ID, 대성 A·한빛 B) |
| 이렇게 바꾸면 됨 | 검사 기록은 `ppe_check` 를 출입 로그와 조인해 시각·게이트·카드를 가져옴. 소속은 사원(부서)·하청(업체)에서. 보고서 숫자(판정 수, 위반, 위반율 = 위반 ÷ 판정 × 1,000, 소속별·보호구별·시간대별, 가동일 = 기록 있는 날)는 이 테이블에서 계산. 게이트·하청 배정·사람 번호는 DB 기준으로 |
| 참고 | 보고서 숫자는 DB 목업 기준이라 기존 목업(10월 1,743판정)과 다름. 원인·조치·할 일·결재는 수기 |

### 예시 조회 (사원 검사 기록)

```sql
SELECT l.clock_in_at, l.gate, c.employee_no, d.dept_name, p.result,
       p.helmet, p.shoes, p.vest, p.gloves, p.goggles
FROM ai.ppe_check p
JOIN org.employee_gate_log l USING (employee_gate_log_idx)
JOIN org.employee_card c ON c.card_id = l.employee_card_id
JOIN org.employee e USING (employee_no)
JOIN org.department d USING (dept_code)
ORDER BY l.clock_in_at DESC;
```
