## 기능 목록

### DB·데이터 파이프라인 인프라

| 항목 | 내용 |
|------|------|
| 주요 기능 | 주조(다이캐스팅) 공정 데이터 흐름(원본 → Lake → Mart → AI 학습, 실시간 Kafka → Flink → 추론)을 위한 인프라를 Docker Compose 하나로 구성 |
| 세부 기능 | PostgreSQL 단일 DB 안 `mes`(원본)·`lake`(정제)·`mart`(학습용) 스키마 / 서비스별 계정·권한(원본 삭제 불가) / Kafka + Kafka UI / Spark master·worker / Flink + PyFlink 팀 이미지 / Python 앱 프로젝트 틀(`apps`) / 52개 항목 DB 검증 스크립트 |
| 기술스택 | Docker Compose, PostgreSQL 18.6, Apache Kafka 3.9.2, Kafka UI 1.5.0, Apache Spark 4.2.1, Apache Flink 2.2.1(PyFlink, Python 3.12), Python 3.13 + uv (pandas, openpyxl, psycopg, confluent-kafka, FastAPI, uvicorn, scikit-learn, joblib) — 버전 근거는 [db/README.md](db/README.md) 3절 |
| 연동 | 다른 팀원 앱이 접속: DB `localhost:5432`(컨테이너 `postgres:5432`), Kafka `localhost:9094`(`kafka:9092`), Spark `spark://spark-master:7077`, Flink `flink-jobmanager:8081`. 루트 웹(Next.js)과는 아직 연동 없음 |
| 개발 목적 (사람 주도) | MS 담당 역할(DB 구축)에 따라 팀 기술 스택표·데이터 흐름도를 실무와 비슷하게 구현. 팀원이 같은 환경에서 기능을 붙일 수 있게 함 |
| 관련 경로 | `MS/db/` (설명 문서는 [db/README.md](db/README.md), 이름 규칙은 [db/명명규칙.md](db/명명규칙.md)) |

### 주조 데이터셋 DB 적재 (mes·lake·mart)

| 항목 | 내용 |
|------|------|
| 주요 기능 | KAMP 주조 공정최적화 AI 데이터셋(73,612행)을 원본 → 정제 → 학습용 3단계 테이블로 적재하고, 데이터 덤프로 팀원이 같은 DB를 바로 쓰게 함 |
| 세부 기능 | `mes.investment_casting`: 원본 23개 컬럼 그대로 + `casting_id`(생산일자_생산시각_생산번호, DB 자동 생성 기본키) / `lake.lake_investment_casting`: `casting_id`(→ mes 외래키) + 20개 컬럼 / `mart.mart_investment_casting`: `casting_id`(→ lake 외래키) + 18개 컬럼, `molten_capacity` 결측 행·정답 빈 행 제외(57,295행) / `init/08_data.sql.gz` 덤프로 빈 DB 생성 시 자동 적재 / 시험 적재 스크립트 3개(`tests/load_csv_trial.sql`, `fill_lake_trial.sql`, `fill_mart_trial.sql`) |
| 데이터 처리 기준 | 원본 값은 고치지 않음. 단 데이터 연도는 2021 → 2026으로 변경(원본 CSV 자체 수정). 이상값은 EDA 검토 결과 그대로 둠. 원본 `timestamp`는 재가동마다 바뀌는 날짜 라벨로 보여 날짜+시각만으로는 302쌍이 겹침 → `casting_id`에 생산번호 포함 |
| 기술스택 | PostgreSQL 18.6 (GENERATED 컬럼, 외래키, COMMENT), pg_dump |
| 연동 | AI 학습: `mart.mart_investment_casting`을 계정 `app_ml`로 읽기. 정제·가공은 이후 Spark 작업으로 옮길 예정(지금은 시험 SQL) |
| 개발 목적 (사람 주도) | 원본 보존 원칙을 지키면서, 테이블 이름·컬럼 구성·제외 기준을 MS가 직접 지정. EDA 결과(결측 행 학습 제외)를 mart에 반영 |
| 관련 경로 | `MS/db/init/03~05, 07, 08`, `MS/db/tests/` |
