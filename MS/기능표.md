## 기능 목록

### DB·데이터 파이프라인 인프라

| 항목 | 내용 |
|------|------|
| 주요 기능 | 열처리 공정 데이터 흐름(원본 → Lake → Mart → AI 학습, 실시간 Kafka → Flink → 추론)을 위한 인프라를 Docker Compose 하나로 구성 |
| 세부 기능 | PostgreSQL 단일 DB 안 `mes`(원본)·`lake`(정제)·`mart`(집계)·`meta`(이력) 스키마 / 서비스별 계정·권한(원본 삭제 불가) / 센서 테이블 월 파티션 / Kafka + Kafka UI / Spark master·worker / Flink + PyFlink 팀 이미지 / Python 앱 프로젝트 틀(`apps`) / 33개 항목 DB 검증 스크립트 |
| 기술스택 | Docker Compose, PostgreSQL 18.6, Apache Kafka 3.9.2, Kafka UI 1.5.0, Apache Spark 4.2.1, Apache Flink 2.2.1(PyFlink, Python 3.12), Python 3.13 + uv (pandas, openpyxl, psycopg, confluent-kafka, FastAPI, uvicorn, scikit-learn, joblib) — 버전 근거는 [db/README.md](db/README.md) 3절 |
| 연동 | 다른 팀원 앱이 접속: DB `localhost:5432`(컨테이너 `postgres:5432`), Kafka `localhost:9094`(`kafka:9092`), Spark `spark://spark-master:7077`, Flink `flink-jobmanager:8081`. 루트 웹(Next.js)과는 아직 연동 없음 |
| 개발 목적 (사람 주도) | MS 담당 역할(DB 구축)에 따라 팀 기술 스택표·데이터 흐름도를 실무와 비슷하게 구현. 데이터셋이 확정되기 전에 구조·권한·검증을 먼저 갖춰, 팀원이 같은 환경에서 기능을 붙일 수 있게 함 |
| 관련 경로 | `MS/db/` (설명 문서는 [db/README.md](db/README.md) 하나) |
