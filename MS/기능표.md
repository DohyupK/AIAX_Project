| 세부 기능 | MS PC `image_sender`(새 양품 샷 → 사진 선택, 불량 사진 5%) → Kafka → Flink `image_ingest` → 서버 사진 받기 API `POST /api/images` (헤더 `X-API-Key`, 같은 샷 재전송은 덮어쓰기) → `/root/images/L{라인}/{yymmdd}/{casting_id}.jpg` + `mes.casting_image` (base64·`image_path`·`image_label`, init 27). 키가 없으면 Flink 는 예전처럼 DB 에 직접 저장 |
| 기술스택 | Python 3, Kafka, PyFlink, FastAPI, psycopg |
| 연동 | DH 서버 배포, JH 품질 2차 검사(base64 읽음) |
| 개발 목적 (사람 주도) | 사진은 MS PC 에, 저장은 서버 `/root/images`, 보내는 형식 base64 JSON, DB 에 base64·경로 둘 다 두기, 키 이름을 MS 가 결정 |
| 관련 경로 | `MS/db/apps/src/apps/image_sender.py`, `MS/db/flink/jobs/image_ingest.py`, `MS/image_api/` (README), `MS/db/init/27` |
