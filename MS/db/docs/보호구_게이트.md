# 보호구 게이트 판정 프로그램 (`apps.gate_judge`)

작성: MS, 2026-11-20. 게이트 옆 PC(시연: 노트북 + 웹캠)에서 돌려요.

## 하는 일

1. 작업자가 카드를 찍어요. 시연에서는 화면 창에 카드 번호(`ec0001`, `vc0001`)나 사번(`e0001`)을 치고 Enter.
2. 카메라가 3초 동안 작업자를 봐요. 프레임마다 감지하고, 결과는 메모리에서만 세요.
3. 보호구별로 판정해요. 그 뒤 출입 기록 1줄과 판정 1줄을 DB에 저장해요.
4. 위반이나 판정 불가면 알람이 울려요. 안전부 직원 카드를 찍고 `P`(통과·오판) 또는 `V`(위반 확인)를 누르면 알람이 꺼지고, 같은 판정 줄에 확인 기록이 남아요.

| 단계 | DB |
|---|---|
| 카드 태깅 | `org.employee_gate_log` (사원) / `org.vendor_gate_log` (하청), IN |
| 3초 판정 | `ai.ppe_check` (보호구 5종 true/false/null, 결과) |
| 안전관리자 태깅 | `ai.ppe_check` 의 `manual_result`, `manual_by`, `manual_at` |

## 판정 규칙

- 사람(Person)이 잡힌 프레임만 세요. 사람이 잡힌 프레임이 절반 미만이면 전부 모름 → 판정 불가.
- 보호구마다 착용으로 잡힌 비율이 60% 이상이면 착용(true), 미착용(`no_*`)으로 잡힌 비율이 60% 이상이면 미착용(false), 둘 다 아니면 모름(null).
- 게이트 필수 보호구(`ai.ppe_gate_rule`) 중 미착용이 하나라도 있으면 **위반**, 아니고 모름이 하나라도 있으면 **판정 불가**, 전부 착용이면 **통과**.
- 신뢰도 기준값은 004 모델의 임계값 결과를 써요. 안전모만 머리카락 오검출 때문에 0.75예요.
- 카드에 그 게이트 출입 권한(`org.gate_card`)이 없으면 판정하지 않고 "NO ACCESS"를 띄워요.
- 알람 중에는 다른 작업자 카드를 받지 않아요. 안전관리자 확인이 먼저예요.

## 판정 사진 (Kafka → Flink → 서버)

판정 3초 동안 박스 친 화면을 Kafka `aiax.ppe.frame` 으로 보내요 (초당 `--frame-fps`, 기본 10장). 판정이 끝나면 결과(판정 번호)도 보내요.
MS PC 의 Flink `ppe_frame_select` 가 판정마다 **보호구 5개가 다 잡힌 화면 중 신뢰도 합이 가장 높은 1장**을 골라 서버에 저장해요 (`/api/images/ppe/<판정번호>`).
화면마다 세션 번호(태깅 1번)를 붙여서, 다른 사람 판정과 섞이지 않아요. Kafka 가 꺼져 있어도 판정은 계속돼요 (`--no-kafka` 로 끄기).

## 실행

`MS/db/apps` 폴더에서 (또는 같은 폴더의 `게이트_실행_DB없이.bat`, `게이트_실행_DB저장.bat`):
```powershell
uv run --group gate python -m apps.gate_judge --gate a --no-db   # DB 없이 시험 (안전관리자 카드 = s 로 시작하는 아무 번호)
uv run --group gate python -m apps.gate_judge --gate a           # DB 에 저장
```

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| `--gate` | (필수) | `a` 또는 `b` |
| `--seconds` | 3 | 판정 시간(초) |
| `--ratio` | 0.6 | 착용/미착용으로 정하는 프레임 비율 |
| `--min-person` | 0.5 | 사람이 잡혀야 하는 프레임 비율 |
| `--camera` | 0 | 웹캠 번호 (안 열리면 1) |
| `--model` | DB 배포 모델 | 모델 파일. 없으면 DB의 보호구 배포 모델 → 004 기본 경로 순서로 찾아요 |
| `--goggles-conf` | 0.45 | 보안경 신뢰도 기준값. 일반 안경을 보안경으로 보면 올려요 (0.5~0.7) |
| `--helmet-conf` | 0.75 | 안전모 신뢰도 기준값 |
| `--no-db` | — | DB 없이 판정만 (화면, 콘솔 출력) |
| `--no-kafka` | — | 판정 사진을 Kafka 로 보내지 않음 |
| `--frame-fps` | 10 | 판정 3초 동안 보낼 초당 화면 수 |

**키는 카메라 창에서 입력해요** (창을 한 번 클릭한 뒤). 콘솔에 치면 안 돼요. 카드 번호 + Enter, Backspace로 지우기, Esc로 종료예요.
실제 RFID 카드 리더기는 대부분 키보드처럼 번호와 Enter를 쳐 줘서, 꽂기만 하면 그대로 쓸 수 있어요.

바로 실행용 파일: `실행_DB없이.bat` (시험), `실행_DB저장.bat` (DB 기록). 더블클릭하면 게이트 a로 실행돼요.
