# MS 로그 기록

모든 로직·에러에는 로그를 남깁니다.  
정식 배포 전에 **지울 로그**와 **지우면 안 되는 로그**를 분류해 둡니다.

> 2026-11-05 기준 MS에는 앱 코드가 없어, 인프라(`MS/db`)가 남기는 로그만 분류합니다. 앱 코드가 생기면 이 표에 추가합니다.

## 지우면 안 되는 로그 (유지)

| 코드/위치 | 내용 | 이유 |
|-----------|------|------|
| DB `meta.ingestion_batch` | 원본 적재 단위별 출처·건수·성공/실패·오류 메시지 | 데이터 출처 추적, 재적재 판단 |
| DB `meta.pipeline_run` | Spark 정제·집계 실행별 입력·출력 건수·파라미터·오류 | 결과 재현·감사 |
| `docker compose logs postgres` | DB 오류·접속 실패 | 운영 장애 분석 |

## 지울 로그 (배포 시 제거·레벨 하향)

| 코드/위치 | 내용 | 이유 |
|-----------|------|------|
| `MS/db/init/00_roles.sh` | `[init] 00_roles 완료` 출력 | 초기화 확인용 |
| `MS/db/tests/verify.sql` | PASS/FAIL 출력 | 검증 실행 때만 사용 |
| `*.log` (예: Flink 빌드 로그) | 빌드·디버그 출력 | 개발용, `.gitignore`로 git 제외 |
