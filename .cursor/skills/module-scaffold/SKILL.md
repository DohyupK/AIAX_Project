# 기능 스캐폴드

1. 구현 전 의도 확인 양식으로 승인받는다.
2. `frontend/pages/<기능명>/`, `api/<기능명>/` 생성 (app/backend 명칭 금지).
3. `main/README.md` 레지스트리에 행 추가.
4. 사이드바 노출이 필요하면 `page_registry.md` 등록 승인 문구 후 갱신.
