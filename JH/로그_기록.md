# JH 로그 기록

모든 로직·에러에는 로그를 남깁니다.  
정식 배포 전에 **지울 로그**와 **지우면 안 되는 로그**를 분류해 둡니다.

## 지우면 안 되는 로그 (유지)

| 코드/위치 | 내용 | 이유 |
|-----------|------|------|
| (예) | request_id, 에러 코드 | 운영·감사 |
| `frontend/pages/main_dashboard/MainDashboard.tsx` `console.error("[main_dashboard] 메모 저장 실패")` | 메모 쿠키 저장 실패 (쿠키 차단 등). 용량 초과는 로그 없이 화면 안내 | 사용자 데이터 유실 추적 |
| `frontend/pages/main_dashboard/MainDashboard.tsx` `console.warn("[main_dashboard] 메모 불러오기 실패")` | 메모 쿠키 손상·해석 불가 | 데이터 손상 추적 |
| `api/hr/router.py` `log.info("사원 추가/수정/삭제 …")` (로거 `jh.hr`) | 인사 데이터 변경: 대상 사번·변경자 사번·바뀐 항목 이름 (개인정보 값은 남기지 않음) | 인사 변경 감사 추적 |
| `api/casting/router.py` `log.exception("공정 … 조회 실패")` (로거 `jh.casting`) | 공정 DB 조회 실패 (라인·날짜) | DB 장애 추적 |
| DB `org.hr_access_log` (API가 기록) | 인사 정보 조회·변경: 누가·언제·무엇을·어느 등급으로 | 개인정보 접속기록 (법적 보관 대상) — 삭제 금지 |
