# JH 로그 기록

모든 로직·에러에는 로그를 남깁니다.  
정식 배포 전에 **지울 로그**와 **지우면 안 되는 로그**를 분류해 둡니다.

## 지우면 안 되는 로그 (유지)

| 코드/위치 | 내용 | 이유 |
|-----------|------|------|
| (예) | request_id, 에러 코드 | 운영·감사 |
| `frontend/pages/main_dashboard/MainDashboard.tsx` `console.error("[main_dashboard] 메모 저장 실패")` | 메모 쿠키 저장 실패 (쿠키 차단 등). 용량 초과는 로그 없이 화면 안내 | 사용자 데이터 유실 추적 |
| `frontend/pages/worker_safety/WorkerSafetyDashboard.tsx` `console.warn("[worker_safety] 보고서 창 열기 실패 (팝업 차단)")` | 보고서 창 팝업 차단 | 현장 PC 팝업 정책 문제 추적 |
| `frontend/pages/main_dashboard/MainDashboard.tsx` `console.warn("[main_dashboard] 메모 불러오기 실패")` | 메모 쿠키 손상·해석 불가 | 데이터 손상 추적 |
