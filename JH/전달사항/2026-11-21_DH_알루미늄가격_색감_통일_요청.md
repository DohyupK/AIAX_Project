# 알루미늄 가격 페이지 색감 통일 요청 (JH → DH)

- 날짜: 2026-11-21
- 요청: JH (사용자 요청 「알루미늄 가격 페이지 색감을 다른 페이지와 동일하게」)
- 대상: `DH/frontend/pages/al_price/` (DH 소유)
- **처리: DH 승인 → JH 가 아래 표대로 `AlPrice.module.css` 만 수정 (2026-11-21).** 변수 8개 교체 + `--al-soft`·`--al-on` 추가, 직접 적힌 어두운 색 6곳 교체. `PriceChart.tsx`·로직은 그대로. 1280·460 에서 배경·글자 확인

## 무엇이 다른가

다른 페이지(공정 최적화·품질 검사·경영 리포트 등)는 **밝은 바탕**(연회색 배경 + 흰 카드)인데, 알루미늄 가격 페이지만 **어두운 바탕**(남색 그라데이션 + 짙은 카드)입니다. 사이드바·헤더가 밝은 상태에서 본문만 어두워서 따로 노는 느낌이 납니다.

## 바꿀 값 (`AlPrice.module.css` `.page` 의 변수만 바꾸면 대부분 해결)

다른 페이지가 쓰는 색 = `JH/frontend/pages/process_optimization/ProcessOptimization.module.css` 의 `.page` 변수.

| 지금 (`--al-*`) | 값 | → 바꿀 값 | 다른 페이지 변수 |
|---|---|---|---|
| `--al-bg` | `#0f1419` | `#eef1f5` | `--bg` |
| `--al-panel` | `#1a222c` | `#ffffff` | `--panel` |
| `--al-line` | `#2c3a48` | `#dde3ea` | `--line` |
| `--al-text` | `#e8eef4` | `#0f1b2d` | `--ink` |
| `--al-muted` | `#8b9aab` | `#5b6779` | `--muted` |
| `--al-accent` | `#3d8bfd` | `#2563c9` | `--accent` |
| `--al-up` | `#3ecf8e` | `#16875b` | `--ok` |
| `--al-down` | `#f07178` | `#cf2f2f` | `--bad` |

## 변수 밖에 직접 적힌 어두운 색 (같이 교체)

| 위치 | 지금 | → 바꿀 값 |
|---|---|---|
| `.page` 배경 `radial-gradient(... #1a3a5c55 ...)` | 남색 번짐 | 삭제 (`background: var(--al-bg)` 만) |
| `.error` | `#8b3a3a` / `#2a1515` / `#f0b4b4` | 테두리 없음 / `#fbe5e5` / `#cf2f2f` (다른 페이지 `.errorBox`) |
| `.tabOn` 배경 | `#243044` | `#eaf1fe` (글자 `#1d4ed8`, 테두리 accent) |
| `.table th` 배경 | `#151c24` | `#f4f6f9` (`--soft`) |
| `.table tbody tr:hover` | `#212b36` | `#f4f6f9` |
| `.pageOn` 배경 | `#243044` | `--al-accent` + 글자 흰색 (경영 리포트 페이지 번호와 같게) |

차트 선·눈금(`PriceChart.tsx`)은 이미 변수(`--al-line`, `--al-accent`)를 써서 위 표만 바꾸면 같이 바뀝니다.

## 다크 모드

사이드바·헤더는 `<html class="dark">` 로 다크 모드를 지원합니다(`JH/frontend/common/theme`). 다른 본문 페이지는 아직 다크 모드 색을 따로 두지 않았으므로, 이 페이지도 우선 **밝은 색만** 맞추면 다른 페이지와 같아집니다.
