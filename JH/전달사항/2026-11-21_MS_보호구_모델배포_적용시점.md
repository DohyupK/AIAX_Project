# 보호구 모델 배포 적용 시점 안내 (JH → MS)

- 날짜: 2026-11-21
- 관련: Model Management 「배포」 버튼 (JH, `POST /api/models/{id}/deploy`)

## 내용

Model Management 에서 「보호구 착용 위반」(SAFE-PPE) 모델을 배포하면 `ai.model_registry.deployed` 만 바뀝니다.
게이트 판정 프로그램(`MS/db/apps/src/apps/gate_judge.py`)은 **시작할 때** 배포 모델(`deployed_model()`)을 읽으므로,
**프로그램을 다시 시작해야 새 모델이 적용**됩니다. 화면에도 「보호구 판정 프로그램(게이트 PC)을 다시 시작하면 새 모델이 적용됩니다」라고 안내합니다.

- 모델 파일은 게이트 PC 에 있어 JH 서버가 미리 열어 확인하지 못합니다 (품질 1차·2차는 배포 전 확인).
- 실행 중 자동 전환이 필요하면 MS 쪽에서 주기적으로 배포 모델을 다시 읽도록 바꾸는 것을 검토해 주세요 (JH 는 수정하지 않음).
