- 작성: JH, 2026-11-19
- 대상: DH (루트 권한·서버 배포·데이터 수집 파이프라인)
- 함께 보는 문서: [2026-11-19_MS_공정실시간_샷수집_Flink_요청.md](2026-11-19_MS_공정실시간_샷수집_Flink_요청.md) (MS 쪽 Flink job·mes 목업 삭제)
- 관련: PR #29, [DB연동_내역/2026-11-16_JH_process_optimization.md](../../DB연동_내역/2026-11-16_JH_process_optimization.md), [JH/기능표.md](../기능표.md) 공정 최적화 「변경 (2026-11-19)」

## 요약

공정 최적화 대시보드에 **실시간 따라가기**를 넣었습니다. 날짜가 오늘(KST)이면 `mes.investment_casting` 에 새로 쌓이는 샷을 5초마다 받아 설비 애니메이션·변수 모니터·관리도·알람이 따라가고, 지난 날짜는 지금처럼 처음부터 재생합니다.
JH 화면은 **mes 원본만** 읽으므로, 샷이 mes 에 들어오기만 하면 JH 코드 변경 없이 동작합니다. 실제 데이터를 흘려보내려면 아래가 필요합니다.

## 요청

| # | 요청 | 이유 |
|---|------|------|
| 1 | **PR #29 병합 + JH API·프론트 서버 배포** | 새 API `GET /api/casting/live`, `/api/models/me`·`/deployed`, `/api/report/*` 가 배포 서버에 없어 지금 `localhost:3000` 화면이 404·「불러오지 못했습니다」. `JH/api/main.py` 에 라우터 1줄(report) 추가됨 → API 재시작 필요. 새 패키지 없음 |
| 2 | **샷 데이터 producer** — Kafka 토픽(예: `aiax.shot.ingest`)으로 샷 1건 = 메시지 1건 | 실제 설비 센서가 없으면 **시뮬레이터**: 지난 데이터(삭제 전 백업 등)를 실제 설비 사이클 간격(약 155초, 라인별)으로 오늘 날짜·현재 시각을 붙여 보냄. 이미지 producer(`DH/api/image_pipeline`)와 같은 방식 |
| 3 | **메시지 형식은 MS 와 맞춤** | MS 요청서 「메시지 형식」 표 기준. JH 화면이 읽는 칼럼이 빠지면 변수 모니터·1차(ML) 점수가 비어 보임 |
| 4 | **이미지는 샷 뒤에** 보내도록 순서 | `mes.casting_image.casting_id` → `mes.investment_casting` 외래키. 샷이 먼저 들어가야 이미지 저장 성공 |
| 5 | **전송 시작 전 MS 의 mes 목업 삭제 완료 확인** | 목업이 11-30 까지 미리 들어가 있어 실데이터와 같은 날·시간대에 섞임(생산량·불량률 두 배, `casting_id` 충돌 가능) |

## 진행 순서 (제안)

```
1. DH  PR #29 병합·배포                         ← 지금 바로 가능
2. MS  샷 수집 Flink job + 메시지 형식 확정
3. DH  샷 producer / 시뮬레이터
4. MS  mes 목업 삭제 (참조 테이블·변경 기록 트리거 처리)   ← 전송 직전
5. DH  전송 시작 (샷 → 이미지 순)
   → JH 공정 최적화 「● 실시간」에 새 샷이 5초 안에 나타남
```

## JH 쪽 동작 참고

| 항목 | 내용 |
|------|------|
| 실시간 API | `GET /api/casting/live?line=&after=` — 오늘(DB 서버 시계 KST) 샷 중 **현재 시각 이전만**. 첫 조회 최근 200샷, 이후 `after`(마지막 `casting_id`) 이후만(최대 500) |
| 조회 주기 | 5초 (화면이 열려 있고 탭이 보일 때만). 화면에 최근 2,000샷까지 유지 |
| 날짜 목록 | `/api/casting/dates` 는 오늘 이후 날짜를 빼고 줌 (품질 검사도 같음) |
| 지연 | Kafka → Flink → DB 시간 + 최대 5초. 설비 애니메이션은 샷이 오면 한 바퀴, 없으면 마지막 단계에서 대기 |
| 확인값 (11-19 21시, 목업) | 첫 조회 200샷 0.9초, 증분 조회 정상, 날짜 바뀜 처리 정상 |
