# 로딩 체감 완화 — JH가 같은 방식으로 되돌리지 말 것

- 대상: JH 주조 프론트 (`frontend/common/casting`, 공정·품질 대시보드)
- 작성: DH (루트 권한, JH·MS 허가 하에 반영)
- 날짜: 2026-11-17

## 증상 (재발 시)

메뉴 전환 시 「페이지를 불러오는 중…」이 길게 보이거나, 마운트 후 「데이터를 불러오는 중…」이 끝나지 않음.

## DH가 이번에 반영한 것

1. 루트 `app/loading.tsx` — 스켈레톤 (문구만 두지 않음). **루트 변경은 DH 문의.**
2. `api.ts` — fetch **10초 타임아웃** (`AbortSignal`). 무한 pending 금지.
3. `useShotStream` — `date` 없을 때 `loading=true`로 붙잡지 않음 (dates 조회와 분리).
4. `DiecastScene` — `SpcChart`와 같이 `next/dynamic` 분리 (초기 라우트 청크 축소).
5. 공정·품질 — 헤더·배너(셸) 유지, 데이터 패널만 로딩/에러.

## JH에게: 다시 만들지 말 것 (금지·권장)

| 하지 말 것 | 이유 | 대신 |
|------------|------|------|
| 무거운 UI(`DiecastScene`·큰 차트·sceneRenderer)를 페이지에 **정적 import로 되돌리기** | 라우트 청크↑ → 「페이지를 불러오는 중」이 다시 길어짐 | `next/dynamic` + 패널 fallback 유지 |
| `get()` / casting fetch에서 **타임아웃 제거** | API·DB hang 시 「불러오는 중」고착 | `FETCH_TIMEOUT_MS` 유지·필요 시만 조정 |
| `useShotStream`에서 `!date`일 때 **loading을 true로 고정** | dates API가 느리면 무한 로딩 | dates는 부모, shots loading은 date 있을 때만 |
| 데이터 올 때까지 **헤더·배너까지 통째로 숨기기** | “페이지가 안 뜬다” 체감 | 셸 먼저, 패널만 로딩 |
| 루트 `app/loading.tsx`를 **문구만 있는 빈 UI로 되돌리거나 무단 삭제** | 체감 악화·루트는 DH 권한 | 스켈레톤 유지, 변경 시 DH 문의 |
| “청크가 렉의 원인”이라며 **dynamic을 전부 제거** | 청크는 초기 번들 축소용(2026-11-15 목적). 제거하면 cold 진입만 나빠짐 | 무거운 것만 분리, 데이터·타임아웃은 별도 |

## 참고

- 청크(`next/dynamic`) 목적: 배포·메뉴 전환 시 **필수 UI만 먼저** 받게 하는 것. 렉 전부가 청크 때문은 아님.
- 실데이터 `real=true`·하루치 `predictions` 용량은 **별 이슈**(증분 API 등은 후속). 이번에 정책 바꾸지 않음.
