- 작성: JH / 2026-11-21
- 상태: 요청 (루트 변경은 DH 승인 완료 — `app/login`·`app/signup`·`middleware.ts`·`next.config.ts`·`page_registry.md`)
- 기능 설명: [`JH/기능표.md` 로그인·회원가입](../기능표.md#로그인회원가입-auth), DB: [`DB연동_내역/2026-11-21_JH_auth_login.md`](../../DB연동_내역/2026-11-21_JH_auth_login.md)

## 1. 서버 `.env` 에 키 추가 (값은 서버에서 새로 만들 것 — PC 값 복사 금지)

```bash
cd /root/AIAX_Project
python3 -c "import secrets; print('AUTH_SECRET=' + secrets.token_urlsafe(48))" >> .env
echo "ADMIN_ID=admin" >> .env
echo "ADMIN_PASSWORD=<영문+숫자 12자 이상 — 직접 정해서 JH에게 따로 전달>" >> .env
```

- `JH_API_ORIGIN` 은 서버에 **넣지 않음** (nginx 가 `/api` 를 JH API 로 보냄)
- `NEXT_PUBLIC_API_BASE_URL` 은 지금처럼 `https://gknushift.freemyip.com` (같은 주소라 쿠키 정상)
- `AUTH_SECRET` 이 없거나 32자 미만이면 로그인 API 500·모든 페이지가 로그인 화면으로 감

## 2. 배포

```bash
git pull origin dev
systemctl restart myapp
```

- 새 패키지 없음 (`uv sync`·`pnpm install` 불필요)
- 계정 저장소 `JH/data/auth.db` 가 처음 가입 때 자동 생성 — `JH/data/` 쓰기 권한 필요, **git 에 없으므로 서버 백업 대상**

## 3. 확인

1. `https://gknushift.freemyip.com/` → 로그인 화면으로 이동
2. `ADMIN_ID` / `ADMIN_PASSWORD` 로 로그인 → 메인, 헤더에 「관리자」 배지
3. 「회원가입」 → 본인 이름·사번으로 가입 → 로그인

## 4. DH 폴더 요청

- **Shift 챗봇 버튼(HyejinBot)** 이 로그인·회원가입 화면에도 보이고, 폰에서는 회원가입 버튼과 겹침 → `/login`·`/signup` 에서 숨겨 주세요.
  JH 는 같은 방식으로 인수인계 버튼을 숨김: `usePathname()` + `AUTH_PAGES` (`JH/frontend/common/auth/token.ts` 에서 import 가능)
- 루트 `개발과정/확장가능성.md` 의 「로그인/RBAC 지금 없음」 문구 갱신
- DH API(알루미늄 시세 등)는 로그인 검사 없음 — 필요하면 세션 쿠키 `shift_session` 검증 방식 공유 가능 (`JH/api/auth/core.py parse`)

## 5. MS·DH 검토 (DB 설계)

로그인·회원가입 정식 테이블은 아직 없음 — 지금 칼럼(`user_id`·`password_hash`·`employee_no`·`user_name`·`email`·`created_at`·`last_login_at`) 그대로 `org` 스키마 테이블 제안. 생기면 JH 가 `JH/api/auth/store.py` 만 교체.
