# 전달사항 — 공정 최적화 서버 에러: JH API 재배포 요청 (JH → DH)

- 작성: JH, 2026-11-20
- 대상: DH (서버 배포)
- 관련 커밋: `ccf1f12` 공정 최적화: 알람 로그 → 관리도 알림 (`dev` 에 이미 있음)

## 증상

배포 서버 `https://gknushift.freemyip.com/casting/process-optimization` 화면에 에러가 뜸.

## 원인

서버 JH API(:8000)가 `ccf1f12` 이전 코드로 실행 중. 화면이 새로 호출하는 `GET /api/casting/limits` 가 서버에 없어 404.

| 확인 (2026-11-20, 서버에 직접 호출) | 결과 |
|------|------|
| `/api/casting/dates` · `/live` · `/predictions` · `/model` · `/spc` | 정상 |
| `/api/casting/limits?line=line_no1` | **404 `{"detail":"Not Found"}`** — 라우트 자체가 없음 (코드의 404 문구는 「… 관리선이 없습니다.」) |

DB·센서 데이터 문제 아님. 코드 수정 없음, 새 패키지 없음.

## 요청

서버에서 최신 `dev` 받기 + 재시작 (Next 빌드·API 둘 다 갱신)

```bash
git pull origin dev
systemctl restart myapp
```
