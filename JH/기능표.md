### 공정 최적화 대시보드 (process_optimization)

| 항목 | 내용 |
|------|------|
| 주요 기능 | 주조 공정 샷별 공정 변수 모니터링·관리도(SPC) 대시보드 |
| 세부 기능 | (2026-11-11 온도 제어 → 공정 최적화로 개편) 상단 왼쪽 흰색 빈 칸(기능 미정). 상단 오른쪽 ① 지표: 오늘 생산 샷·시간당 샷(첫~마지막 샷 시간 기준)·평균 사이클(설비 사이클)·범위 이탈 샷(8개 변수 중 하나라도 p5~p95 밖) ② 알람 로그: 클릭 시 상세 팝업(메인 대시보드 공지 팝업과 동일 동작 — 바깥 클릭·Esc·× 닫기, 등급·시각·샷·관련 변수·조치 가이드). 공정 변수 모니터 4×2(슬리브 온도·사출압력·상형 온도1·2 / 설비 사이클·냉각수 온도·하형 온도1·2) — 칸 클릭 시 관리도 변수 선택. 관리도(SPC): 최근 50샷 점·선, UCL/LCL 실선·CL 점선 + 값 표시, 한계는 그날 처음 100샷 기준으로 고정(기준 구간 이상점 제외 후 1회 재계산, AIAG Phase I 방식). 변수별 방식 — ① 온도 6종(슬리브·상형1·2·하형1·2·냉각수): EWMA 관리도(λ=0.2, L=3, σ=기준 구간 전체 표준편차, 한계 = CL ± L·σ·√(λ/(2-λ))), 그래프는 EWMA 값, 한계 밖만 판정(연속 규칙 미적용) ② 사출압력·설비 사이클: 개별값 관리도 I-MR(CL ± 2.66·MR̄) + Nelson 규칙 1(한계 밖)·2(9점 연속 한쪽)·3(6점 연속 상승/하강). 위반 점 빨강, 마우스 올리면 샷·시각·실측값(온도는 EWMA 값 포함)·위반 규칙 툴팁 (2026-11-11). 기준 구간은 백엔드·DB 연결 후 실시간/과거 정상 데이터로 교체 예정(현재 목업은 05~08시 가동 초기 구간이라 이후 샷 대부분이 이탈로 표시됨). 목업 모드는 2021-10-07 데이터를 0.4초 간격으로 재생(재생 속도 선택 삭제, 2026-11-11). 불량 확률 타임라인·판정 카드·임계값·일별 추이·샷 테이블은 삭제 |
| 기술스택 | Next.js(React) + CSS Modules, 차트는 SVG 직접 구현 — 추가 라이브러리 없음 |
| 연동 | 목업 JSON(`frontend/common/casting/mock/`, Investment_Casting.csv 추출). 실제 API 전환 지점은 `frontend/common/casting/api.ts` (`NEXT_PUBLIC_USE_MOCK`, `NEXT_PUBLIC_API_BASE_URL`) |
| 개발 목적 (사람 주도) | JH가 별도 작성한 대시보드(바탕화면 data/nextjs-defect-prediction)를 팀 구조에 맞춰 이식 (2026-11-06) |
| 관련 경로 | `frontend/pages/process_optimization/`, `frontend/common/casting/`, `main/process_optimization.ts`, 루트 `app/casting/process-optimization/page.tsx`(2026-11-11 루트 승인 후 URL 변경) |
| 자체 점검 | `node JH/frontend/pages/process_optimization/spc.check.ts` (I-MR·EWMA 관리 한계·Nelson 규칙 1·2·3) |
| 알려진 이슈 | 실제 모드의 오늘 날짜가 UTC 기준(`toISOString`) → KST 오전 9시 전에는 전날 조회. 로그 미적용 |
